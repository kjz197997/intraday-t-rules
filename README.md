# 分时做T 自动监控 · 规则说明（公开征询版）

> 本人是上班族，白天电脑基本关机，靠自己盯分时做T不现实，于是写成了一套「1 分钟分时自动监控 + 企业微信推送」的小工具。下面把规则和近几日结果全摊开，**主动请大家找漏洞**。文中不含任何账号、密钥、持仓与资金信息。

## 〇、怎么参与（先看这里）

我自己再加参数已经收益很小了，**真正缺的是别人来挑毛病**。三种方式，任选一种：

1. **直接开一个议题（最快，约 30 秒）**：<https://github.com/kjz197997/intraday-t-rules/issues/new> ，标题随便写，正文建议按四段写：
   ```
   现象：哪种行情下会错
   依据：用哪只票 / 哪天的分时验证的
   建议改法：具体阈值或条件
   预期影响：会多报还是少报，副作用是什么
   ```
2. **直接改文档提 PR**：详细见 [界面与功能征询.md](界面与功能征询.md)，欢迎补回测数据、修正错误描述。
3. **只想看结论**：所有意见建议会汇总进 [反馈台账.md](反馈台账.md)，含采纳/未采纳及理由。

现在最想要答案的三件事：

- **规则挑错**：第五节「四层拦截」哪一条最可能系统性出错？
- **界面设计**：5 个页面（多股同列 / 形态图谱 / 自动监控 / 同屏做T / 模拟盘）怎么改更好用？
- **回测复核**：用你熟的票按同样口径跑一遍，把你我结果不同的地方贴上来。
